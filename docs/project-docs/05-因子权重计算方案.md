# 因子权重计算方案

优先实现**五年 IC 定组内权重 + MCTS 搜组间系数与偏置**，用**逻辑回归和单隐藏层网络**做训练对照。两套方案共用 20 个因子、历史数据和回测引擎。先检验 5 个交易日，再用 10 个交易日做一套独立实验。

## 一、先定义预测什么

在交易日 `t` 收盘时，用当时已经知道的 20 个因子评分。沿用次日开盘成交的口径，目标收益从 `t+1` 的复权开盘价算起。信号用于买入、卖出或保持原仓位，实际成交、费用和收益由统一的回测规则记录。

| 目标 | 用来核对预测的实际结果 |
| --- | --- |
| 未来 5 日收益 | `t+6` 的复权开盘价 ÷ `t+1` 的复权开盘价 − 1 |
| 未来 10 日收益 | `t+11` 的复权开盘价 ÷ `t+1` 的复权开盘价 − 1 |
| 未来涨跌 | 对应持有期的实际收益大于 0 记为 1，其余记为 0 |

`MOM20` 的 20 日是向后看的因子窗口，5 日和 10 日是向前看的预测窗口，五年则是用多少历史来估计权重。三个时间长度各有用途。

两套方案共用 A–F 六组与 `FACTOR_NAMES` 的 20 项顺序。先沿用个股评分页的口径，用信号日前 40 个交易观测把因子换成标准化值 `z`，并限制在 `[-3, 3]`。两套方案用相同的缺失处理和日期，报告可评分覆盖率。季度指标往往连续多日相同，应单独检查这个标准化口径在基本面组的覆盖率和辨识度。

## 二、方案一用 IC 和 MCTS

### 单只股票可以按日期算相关度

给一只股票训练自己的权重时，每个历史信号日填一行，左边是当天用于评分的 MOM20 标准化值，右边是对应的未来 5 日实际收益。取五年内已知结果的行，**在同一只股票的历史日期里对两列各自排名，保留同一日期的配对，再算一次 Spearman 相关**。并列值用平均名次。A 组四个因子分别算，再用各自相关度除以四项绝对值之和，得到组内权重。[Spearman 排名相关系数的定义](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/rankcorr.htm)

文件末尾的单因子算例用 `t` 到 `t+5` 的复权收盘价检验收盘收益。和本页次日开盘成交的回测口径对齐时，5 日用 `t+1` 到 `t+6` 的复权开盘价，10 日用 `t+1` 到 `t+11` 的复权开盘价。

**五年里的每一天提供一对样本。** 分别把 `MOM20`、`MOM60`、`MOM120`、`REV5` 的标准化历史列与同一列实际收益按日期配对。每个因子使用自身有效的配对样本，从整个五年窗口得到一个相关系数，因此 5 日版本有四个系数，10 日版本也有四个。

**如果已经把五年拆成五段算了五个系数，先用它们检查稳定性。** 观察各年符号是否一致、关系是否主要集中在某一年。首版用原始配对样本直接计算一次五年整段相关度。分年系数的平均值通常和整段相关度不同，滚动窗口还会重复包含很多相同样本。如果要让近期样本占更大权重，可以另定一种加权规则，在校准段比较后冻结。

单股时间序列相关度回答的是「这只股票的 MOM20 比自己平时强的日子，后续收益是否通常也更高」。下面的横截面 RankIC 回答的是「同一天，哪只股票的 MOM20 更强，哪只股票之后表现更好」，适合给股票池估计一套共用权重。

BaoStock 的 `query_history_k_data_plus` 按股票代码和日期范围取历史日线，可以用于补该股多年的行情。项目当前只往前取 275 个自然日，这是快照工具的配置。训练要另取更长的历史，并为动量和标准化留出预热区间。BaoStock 也有按指定日期获取全市场 A 股日线的接口，可以供多股方案使用。完整的 20 因子历史还要补齐按日期对齐的总市值和财报指标。[BaoStock 历史数据与本地更新指南](https://www.baostock.com/mainContent?file=localdatafactorInfo.md)

### 手算某一天的 MOM20 相关度

**每只股票配一对数，一个是信号日的 MOM20，一个是随后实际发生的 5 日收益。** 先用「当天复权收盘价 ÷ 20 个交易日前的复权收盘价 − 1」算出 MOM20。由于评分使用标准化后的值 `z`，算相关度也用同样处理过的值。5 日收益用 `t+6` 的复权开盘价除以 `t+1` 的复权开盘价再减 1。例如乙股从 10 元到 10.30 元，收益是 `10.30 ÷ 10 − 1 = +3%`。

| 股票 | 当日 MOM20 标准化值 | t+1 复权开盘 | t+6 复权开盘 | 5 日收益 | MOM20 排名 | 收益排名 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 甲 | −1.0 | 10.00 | 9.90 | −1% | 1 | 1 |
| 乙 | 0.0 | 10.00 | 10.30 | +3% | 2 | 3 |
| 丙 | +0.5 | 10.00 | 10.10 | +1% | 3 | 2 |
| 丁 | +1.5 | 10.00 | 10.50 | +5% | 4 | 4 |

两份排名都按从低到高编号。乙和丙各差一名，甲和丁的名次一致。这个例子没有并列名次，直接代入公式。每只股票的两个名次之差记为 `d`，平方后加起来是 `0² + (−1)² + 1² + 0² = 2`，四只股票代入得 **`RankIC = 1 − 6 × 2 ÷ [4 × (4² − 1)] = +0.80`**。实际数据有并列时，用平均名次，再对两个排名列表计算 Pearson 相关。无法计算相关度的日期跳过并记录。[Spearman 排名相关系数的定义](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/rankcorr.htm)

### 股票池版汇总五年每日 RankIC

在历史股票池中，对五年里的每个有效信号日重复上面这一遍。只有 5 日收益已经完整发生的日期才能计入。把当天得到的相关度加起来，除以有效天数。比如 1,000 个有效日的 RankIC 加总为 50，MOM20 的五年平均 RankIC 就是 `50 ÷ 1000 = +0.05`。正值表示 MOM20 较高的股票往往收益排名也较高，负值表示方向相反。这一做法给股票池估计一套共用权重。10 日版本用 `t+11` 的开盘价替换终点，重新计算平均 RankIC。[AlphaForge 的 IC 与因子组合](https://arxiv.org/html/2406.18394v5)

### 把四个相关度换成 A 组四个权重

单股版用各因子的五年整段 Spearman 相关度，股票池版用各因子的五年平均 RankIC。对每组，把每项相关度除以该组所有有效相关度的绝对值之和。权重的正负号已包含方向，直接乘标准化因子值。训练期内有效样本太少或历史表现接近零的因子可以按统一门槛置零，门槛用校准段确定。整组没有有效权重时，组信号记为零。

| A 组示例 | MOM20 | MOM60 | MOM120 | REV5 |
| --- | ---: | ---: | ---: | ---: |
| 五年训练相关度（示例） | +0.05 | +0.03 | +0.01 | −0.01 |
| 组内权重 | +0.50 | +0.30 | +0.10 | −0.10 |
| 一只股票今天的标准化因子值 | +1.00 | +0.50 | 0.00 | +1.00 |

`wA1 = 0.05 ÷ (0.05 + 0.03 + 0.01 + 0.01) = +0.50`，它是 MOM20 在 A 组里的乘数。该股今天的 A 组分为 `0.50 × 1.00 + 0.30 × 0.50 + 0.10 × 0.00 − 0.10 × 1.00 = 0.55`。IC 高低反映单个因子的历史关系。几个因子可能重复解释同一段涨跌，因此还要用样本外对照测组合是否有效。

### 用 MCTS 定组间系数和偏置

```text
S     = kA × (wA @ zA) + kB × (wB @ zB) + … + kF × (wF @ zF)
score = clip((50 / 3) × S + 100 × bias, 0, 100)
```

`@` 表示同组因子与各自权重相乘后相加。`50 / 3` 把 `[-3, 3]` 的综合信号换成分数。比如 `MOM20` 给这只股票贡献的分数是 `(50 / 3) × kA × 0.50 × 1.00`，原始 IC 提供估计组内权重的依据。若先把组输入 A 到 F 各乘 `50 / 3`，外层就正好是 `ka × (wA @ A) + … + bias × 100`。

- 六组有效系数非负且合计为 1。MCTS 只给指定组选离散档位。例如只搜 A 和 C 时，其他四组固定，A 和 C 按所选档位分配剩余权重。
- `bias = 0.50` 对应 50 分起点。校准时固定买卖线，搜索 `bias` 就是在测试交易信号整体上移或下移的效果。
- 固定该轮的组内权重，每套候选用相同仓位、成交限制和成本跑校准段。首版用扣费后的年化夏普评价候选，并记录换手。全六组开放时最多是六个组档位和一个偏置档位，20 个组内权重仍是用历史估计的量。
- 输出的 `score` 是交易信号分。若需要展示可核验的上涨概率，另用校准数据拟合从信号到实际上涨频率的映射。

## 三、方案二用梯度学习和反向传播

用相同的 20 个标准化因子预测同一持有期的上涨标签。模型报出上涨概率 `p`，二分类交叉熵根据实际涨跌给预测扣分，优化器再根据梯度调整权重。

| 模型 | 学什么 | 用途 |
| --- | --- | --- |
| 逻辑回归 | `p = sigmoid(b + β1 × z1 + … + β20 × z20)`，20 个因子系数和 1 个截距 | 检验直接学习 20 个系数的线性基线，可以加 L2 约束权重大小 |
| 单隐藏层网络 | 20 个输入 → 4 至 8 个带非线性激活的隐藏单元 → 1 个上涨概率，共 89 至 177 个参数（含偏置） | 检验因子之间的配合、非单调关系是否改善样本外预测，用校准段早停 |

用逻辑回归可以直接看每个因子的系数。小网络可以让一个隐藏单元同时使用动量和波动等不同组的因子，训练时通过反向传播更新连接权重。两种模型的交易阈值在校准段确定，测试期冻结。输出概率仍要检查它和实际发生频率是否一致。[反向传播原论文](https://www.nature.com/articles/323533a0)

## 四、数据、更新频率和回测

1. **离线准备历史。** 单股方案先取目标股票的历史。需要多股共用权重时，可先用约 30 至 50 只股票验算横截面 RankIC。按历史时点确定股票池、对齐财报公告可用日和市值，并保留滚动标准化的预热数据。准备好本地「股票 × 交易日」因子表后，两种训练共用。之后增量保存行情与估值，财报在披露后更新。
2. **按时间划分。** 先用较早的五年估计 IC 或训练模型，再用随后一段校准期选 MCTS 档位、模型参数和交易阈值，最后用更晚的月份测试。训练和校准只使用各段内已完全实现的收益标签。跨到下一段才结束的 5 日或 10 日标签剔除。随机打乱会破坏时间顺序。[按时间划分训练、验证和测试的研究](https://www.aqr.com/-/media/AQR/Documents/Journal-Articles/Empirical-Asset-Pricing-in-Machine-Learning.pdf#page=10)
3. **日常评分轻量更新。** 每天用当前因子与已保存的权重算分。月度更新时，从本地滚动五年历史重新估计组内权重，再校准组间参数。下一月冻结配置。将多个样本外月份串起来报告，例如汇总约一年的表现。
4. **用相同口径对照。** 等权、IC 加权但固定组系数、IC + MCTS、逻辑回归、小型网络、买入持有可共用测试区间与成本口径。5 日和 10 日分别对比。预测层看 RankIC、涨跌命中率和可评分覆盖率，交易层看扣费净收益、夏普、最大回撤和换手。候选很少时，可以用同档位的穷举结果衡量 MCTS 的搜索效果。

## 五、接入项目

```text
数据与因子 → 训练器 fit(X, y, dates, split) → 策略 JSON → predict(doc, x) → 回测与决策
```

策略 JSON 共用 `meta`（训练期、因子顺序、标准化、预测天数）、`model`（`group_linear`、`logistic` 或 `mlp`）、`signal`（得分类型、买卖阈值）及训练指标和搜索日志。决策层读取同一格式，就能识别当前信号是交易分还是上涨概率。

开发顺序为 `strategy/` 的格式与预测入口、`backtest/` 的回测与等权基线、`trainers/` 的 IC + MCTS 和梯度训练器，最后用同一回测生成对比。数据 Agent 提供因子，训练 Agent 产出策略配置，回测 Agent 比较样本外表现，决策 Agent 读取配置给出动作和理由。当前检索工具提供单日快照，训练与回测需要另接入历史因子表。


# 单因子权重计算方法(单只股票)

## 目标
对每个因子 i,用**训练段**数据算出一个权重 w_i,再按组归一化。

## 一、输入

- 训练段内,这只股票每天的 20 个因子值(已标准化)
- 未来 5 日复权收盘收益为 `C(t+5)/C(t) - 1`。若按次日开盘成交校准，用复权开盘收益 `O(t+6)/O(t+1) - 1`。
- 因子分组(A~F 六组)

## 二、计算步骤

**第 1 步:对齐数据**

每个因子 i 取出两列,去掉含 NaN 的行:

```
x = 因子 i 的 N 天序列
y = 对应的未来5日收益序列
```

**第 2 步:算单因子 IC**

```
IC_i = Spearman(x, y)      # 先各自排名,再算相关系数
```

得到 20 个数。

**第 3 步:过滤无效因子**

```
|IC_i| < 阈值  →  IC_i 置 0
```

首版可把 `0.02` 和 `0.03` 作为待比较的筛选阈值，用校准段选定。相邻的 5 日收益共享 4 个交易日的收益，动量因子也有重叠窗口。若要做显著性检验，需要采用考虑时间依赖的方法。[重叠收益样本的统计问题](https://www.boj.or.jp/en/research/wps_rev/wps_1999/data/cwp99e01.pdf)

**第 4 步:组内归一化**

对每个组,令 `S = Σ|IC_j|`(组内所有因子):

```
w_i = IC_i / S       # S = 0 时,该组所有 w 取 0
```

只要组内有因子通过过滤，权重的绝对值之和就是 1。IC 为负则 w 为负，方向自动翻转。

**第 5 步:算组分数**

```
组分数 A_t = Σ w_i · x_i,t        (即 wA @ A)
```

六组按上文公式合成。沿用 0–100 分刻度时，组间加权和乘 `50 / 3`，再加上 `bias × 100` 并限制在 0–100。

## 三、手算示例

动量组 4 个因子,阈值取 0.02:

| 因子 | IC | 过滤后 | 权重 |
|---|---|---|---|
| MOM20 | 0.04 | 0.04 | 0.04/0.09 = 0.44 |
| MOM60 | 0.03 | 0.03 | 0.33 |
| MOM120 | 0.01 | 0(被滤掉) | 0 |
| REV5 | -0.02 | -0.02 | -0.22 |

## 四、代码

```python
import numpy as np
import pandas as pd
from scipy.stats import spearmanr

def calc_factor_ic(factors: pd.DataFrame, fwd_ret: pd.Series) -> pd.Series:
    """factors: 行=日期, 列=因子名(训练段); fwd_ret: 对应的未来5日收益"""
    ics = {}
    for name in factors.columns:
        pairs = pd.concat([factors[name], fwd_ret], axis=1)
        pairs = pairs.replace([np.inf, -np.inf], np.nan).dropna()
        # 两列都需要有变化。常数列没有可用的排序相关度。
        if len(pairs) <= 60 or (pairs.nunique() < 2).any():
            ics[name] = 0.0
            continue
        ics[name] = spearmanr(pairs.iloc[:, 0], pairs.iloc[:, 1])[0]
    return pd.Series(ics)

def group_weights(ic: pd.Series, groups: dict[str, list[str]], thr: float = 0.02) -> dict:
    ic = ic.where(ic.abs() >= thr, 0.0)          # 过滤
    weights = {}
    for g, names in groups.items():
        s = ic[names].abs().sum()
        weights[g] = {n: (ic[n] / s if s > 0 else 0.0) for n in names}
    return weights

```

`GROUPS` 按你的分组写,例如:

```python
GROUPS = {
    "A": ["MOM20", "MOM60", "MOM120", "REV5"],
    "B": ["VOL20", "VOL60", "DVOL20"],
    "C": ["TURN20", "AMIHUD20", "SIZE"],
    "D": ["INTRA20", "CORR20", "VR"],
    "E": ["RSI14", "AMP20"],
    "F": ["EP", "BP", "SP", "ROE", "REVG"],
}

# close 是复权收盘价，factors 是已标准化的因子表，两者都以交易日为索引。
# 先截取训练段的复权价格，再向后找价格，保证标签在训练段内实现。
train = slice("2021-01-01", "2025-12-31")
close_train = close.sort_index().loc[train]
fwd_ret = close_train.shift(-5) / close_train - 1

# 若以次日开盘成交为准，将上面的收益改成以下口径。
# open_train = adjusted_open.sort_index().loc[train]
# fwd_ret = open_train.shift(-6) / open_train.shift(-1) - 1

ic = calc_factor_ic(factors.loc[train], fwd_ret)
w = group_weights(ic, GROUPS)
```

## 五、几个要点

1. **只用训练段**算 IC,测试段不参与。
2. **标签必须在训练段内实现。** 上面先截段再算收益，收盘口径末尾 5 行为空，次日开盘口径末尾 6 行为空。缺失行由 `dropna` 删除。
3. **SIZE、基本面因子**变化很慢,值几乎是常数,滚动标准化后可能全是 NaN 或接近常数,IC 不可靠,建议单独检查。
4. **比较分年相关度和样本外结果。** 可以记录 IC 在不同年份是否同向。若研究多只股票共用一套权重，可额外比较横截面 RankIC，或按事先规定的方法汇总各股的整段 IC。
5. 把 `IC` 和最终 `w` 都存进策略文档的 `model.groups` 里,推理时直接读取。

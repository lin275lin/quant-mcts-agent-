个股因子检索工具

输入股票代码或精确名称，获取最近可用日的 20 个原始因子。14 个价量因子加上 SIZE、EP、BP、SP、ROE、REVG，一共 20 项，与评分方案使用的名单相同。

去哪个文件找代码？

文件负责什么
fetch_stock_factors.py公开入口、并行组织查询、按固定顺序组装 20 个因子。
baostock_session.py登录、登出、连接复用和断线重连。
_symbols.py把股票代码或名称转成统一格式。
_cache.py打开 SQLite，查询、保存和清理缓存。
_sources.py请求日线、市值和财务接口，整理返回字段。
_helpers.py用传入的数据计算 A–E 各组价量因子及估值倒数。每组有自己的计算函数。

包的 __init__.py 只转发公开入口。Agent 可以直接从 tools.fetch_stock_factors 导入。

各数据源提供什么？

默认接口写在_sources.py 中。config.py 维护因子名单和日线回看范围。AkShare 是调用接口的 Python 库，表里列出它实际访问的数据源。用六位股票代码可直接查询，用股票名称则会另外查名称表。

因子数据源怎么算
14 个价量因子BaoStock 前复权日线用价格、成交量、成交额和换手率计算原有指标。
EP、BP、SPBaoStock 日线中的 peTTM、pbMRQ、psTTM用 1 除以对应倍数，保留正负号。比如市盈率 −20 倍得到 EP −5%。倍数为零、无效或缺失时留空。
ROE东方财富财务接口披露的 ROEJQ取最新报告期的加权净资产收益率，再把百分数换为小数。
REVG东方财富财务接口披露的 TOTALOPERATEREVETZ取最新报告期的营业收入同比，并把百分数换为小数。例如 1.82% 返回 0.0182。
SIZE百度直接提供的总市值先把亿元换为元，再取自然对数。

缺失的估值、总市值或财务字段保留缺失值。data_end_date 限制日线及随日线返回的估值。市值和财务读取各自最新快照，用于历史回测前还需要对齐日期。

并行查询与本地缓存

日线、市值和财务并行查询。普通单次查询需要远程日线时，会登录、查询、退出。服务器也可提前登录，在同一进程内查询不同股票时复用连接。SQLite 则负责同一查询的缓存命中。

程序使用 Python 自带的 sqlite3.connect()，首次尝试缓存时创建文件 Project/storage/cache/stock_factor_sources.sqlite3。source_cache 表有 key、expires_at 和 payload 三列。payload 保存接口数据，行情、市值与财务记录保存 15 分钟，名称表保存 24 小时。

在文件资源管理器打开 Project/storage/cache 即可查看数据库文件。目录中的 .gitignore 让数据库文件略过 Git 的变更列表。从 Project 目录执行下面的命令，可用 sqlite3 只读查看键、过期时间和保存的数据。substr 只截取前 160 个字符，以免整张日线表刷满终端。

sqlite3 -readonly storage/cache/stock_factor_sources.sqlite3 "SELECT key, datetime(expires_at, 'unixepoch', 'localtime'), substr(payload, 1, 160) FROM source_cache;"

怎样提前登录并复用连接？

常驻进程可在后台调用 login_baostock()，登录完成后再跑依赖日线的工作。这样应用可以先启动，已有连接可直接用于随后到来的查询。重用只在同一个 Python 进程里生效。BaoStock 共用的连接由锁保护，断线后会重新登录并重试一次。

from tools.fetch_stock_factors import fetch_stock_factor_vector, login_baostock, logout_baostock

login_baostock()
try:
    first = fetch_stock_factor_vector("600519")
    second = fetch_stock_factor_vector("000001")
finally:
    logout_baostock()

示例展示同一进程查两只股票。接入服务器时，由启动阶段的后台任务调用登录，再由关闭阶段调用退出。第一次远程登录依然耗时，之前一次实测登录约 76 秒。当前项目提供了调用接口，服务器启动流程仍待接入。

个股首次查询还能多快？

用三个接口并行做了端到端测速。腾讯日线用于计算价量因子，东方财富估值提供同一交易日的 PE、PB、PS 和总市值，原财务接口直接返回 ROE 和营收同比。测速使用 2026 年 11 月 23 日的数据，从发起请求到算完因子计时，跳过项目的 SQLite 缓存。

股票返回日线有效因子总耗时
600519184 根20 / 201.20 秒
000001184 根20 / 201.47 秒

这是两只股票的一次实测。候选方案上线前还需核对更多样本的日期、复权、换手率单位和数据覆盖。公共接口请求仍会受服务端频次限制，默认工具仍使用原数据源。

需要在线补数据时，可以按供应商分别排队限速，并合并同一只股票、同一截止日的重复请求。东方财富的估值和财务接口应一起计入该源的请求量。如果服务器返回频次限制，按它给的等待时间重试，已有本地记录可标记日期后继续读取。要让新查询也保持稳定延迟，所需历史数据应提前入库。

回测和反复查看股票池时，适合收盘后批量同步原始数据，写入长期本地历史库。查询直接读本地，日线和估值按交易日更新，财务按公告日补齐。Tushare 的日线、每日估值和复权因子支持按交易日取数据，财务指标可取加权 ROE 和营收同比，调用频次由积分权限决定。日线 · 每日指标 · 复权因子 · 财务指标 · 频次权限

怎么调用？

从 Project 目录执行。

python tools/fetch_stock_factors/fetch_stock_factors.py 600519
python tools/fetch_stock_factors/fetch_stock_factors.py 600519 --end-date 2026-11-20
python tools/fetch_stock_factors/fetch_stock_factors.py 600519 --raw-daily

命令行的 factor_count 是字段总数，valid_factor_count 是实际有有限数值的因子数，missing_factors 列出终端显示为 NULL 的因子。每行依次显示英文缩写、数值、中文指标名。

下方的“核对用原始数据”列出 BaoStock 前复权行情和估值原值、百度股市通总市值及日期、东方财富财务百分数及报告期。公告日按接口提供值显示。核对时先在平台上选同一股票和日期，K 线选前复权，市盈率和市销率选滚动口径，财务选按报告期。加 --raw-daily 可把计算使用的全部日线打印成 CSV，用来核对动量和波动率。

from tools.fetch_stock_factors import fetch_stock_factor_vector

result = fetch_stock_factor_vector("600519.SH")
print(result["data_date"])
print(result["vector"]["MOM20"])
print(result["metadata"])

vector 可以按因子名读取，vector_values 是对应的列表，两者使用 FACTOR_NAMES 的顺序。需要查看这些原始因子怎样合成决策信号，可继续读个股评分说明。

保留方案 · 逻辑回归与反向传播

使用相同 20 个因子的历史位置分，例将 Qₜ(x) ÷ 50 作为输入 z。输出 p 是模型对未来上涨的概率估计。逻辑回归提供线性基线，单隐藏层用非线性激活学习因子之间的配合。

模型从因子到概率实验目的
逻辑回归p = sigmoid(b + Σ βᵢzᵢ)20 个系数加 1 个截距，提供可解释的线性对照。
单隐藏层网络h = tanh(W₁z + b₁)，p = sigmoid(W₂h + b₂)20 个输入、4–8 个隐藏单元，共 89–177 个参数。隐藏单元可以同时学习多个组的输入。
六组神经元h_g = 2 × sigmoid(G_g + b_g) − 1，p = sigmoid(b₀ + Σ v_g h_g)以 A–F 六个组分为输入。每组有自己的隐藏层偏置，比较压缩组分前后的预测效果。

训练段用二分类交叉熵 −[y log(p) + (1−y)log(1−p)]，通过反向传播计算梯度，再由优化器更新权重和偏置。校准段设早停、概率阈值和可选概率校准。测试时报告方向命中率、概率误差和扣费后的交易结果。Rumelhart 等的反向传播论文

样本外对照怎么排

  1. 训练段。 准备时点正确的 20 因子历史，求 IC、风险阈值，或拟合梯度模型。百分位按信号日前的历史顺序更新。
  2. 校准段。 MCTS 用扣费后年化夏普选择六个组系数和 bias。梯度方案主要用预测误差校准，并预先固定概率交易阈值。
  3. 测试段。 使用时间上更晚的数据，在相同撮合、仓位和成本口径下比较等权、固定组系数、主模型、逐组移除、买入持有和两种梯度模型。单列覆盖率、净收益、夏普、回撤及换手。
